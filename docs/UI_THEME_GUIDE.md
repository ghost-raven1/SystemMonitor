# 🎨 Руководство по системе тем интерфейса в стиле btop

## Обзор новой системы дизайна

Система мониторинга теперь использует современную систему тем в стиле btop с расширенными визуальными возможностями.

### Основные улучшения дизайна

- **Современная цветовая палитра** - 16+ специальных цветов для различных элементов
- **Градиентные progress-бары** - красивые анимированные индикаторы загрузки
- **Адаптивная типографика** - четкие заголовки и структурированный текст
- **Unicode визуальные элементы** - современные иконки и символы
- **Множественные темы** - темная, неоновая, матричная и другие

## Доступные темы

### 🌑 Темная тема (btop-dark)
**Основная тема по умолчанию**
- Темный фон с яркими акцентами
- Градиентные бары с цветовой индикацией нагрузки
- Оптимальная читаемость в темных терминалах

### ⚡ Неоновая тема (btop-neon)
**Яркая тема для привлечения внимания**
- Высококонтрастные цвета
- Энергичная цветовая схема
- Подходит для презентаций и демо

### 🟢 Матричная тема (btop-matrix)
**Монохромная зеленая тема**
- Стиль "Матрицы" с зеленой гаммой
- Минималистичный дизайн
- Отключенные анимации для аутентичности

### ☀️ Светлая тема (btop-light)
**Светлая тема для светлых терминалов**
- Светлый фон с темным текстом
- Мягкие цвета для комфортного чтения
- Сниженная нагрузка на глаза

## Цветовая схема

### Основные цвета
```c
COLOR_BTOP_BG        // Основной фон
COLOR_BTOP_PANEL     // Фон панелей
COLOR_BTOP_BORDER    // Границы и рамки
COLOR_BTOP_TITLE     // Заголовки
COLOR_BTOP_TEXT      // Основной текст
COLOR_BTOP_TEXT_DIM  // Приглушенный текст
```

### Цвета метрик
```c
COLOR_BTOP_CPU_*     // Цвета загрузки CPU (низкая/средняя/высокая)
COLOR_BTOP_MEM_*     // Цвета загрузки памяти
COLOR_BTOP_TEMP_*    // Цвета температуры
COLOR_BTOP_NET_*     // Цвета сетевой активности
```

### Акцентные цвета
```c
COLOR_BTOP_ACCENT1-4 // Акцентные цвета для выделения
COLOR_BTOP_SUCCESS   // Успешное выполнение
COLOR_BTOP_WARNING   // Предупреждения
COLOR_BTOP_ERROR     // Ошибки
COLOR_BTOP_INFO      // Информационные сообщения
```

## Использование в коде

### Инициализация системы тем
```c
// В начале программы
ui_theme_init();
ui_theme_detect_terminal_colors();
ui_theme_set_theme(THEME_BTOP_DARK);
```

### Рисование элементов
```c
// Заголовок в стиле btop
ui_print_header("СИСТЕМНЫЙ МОНИТОР v2.0");

// Градиентный бар
ui_draw_gradient_bar(y, x, width, percent, COLOR_BTOP_CPU_MED);

// Метрика с иконкой
ui_print_metric("CPU:", "85%", COLOR_BTOP_CPU_HIGH);

// Статус с цветовой индикацией
ui_print_status("НОРМАЛЬНО", 0); // 0 = success
```

### Использование символов
```c
// Иконки
const char* cpu_icon = ui_get_icon("cpu");
const char* mem_icon = ui_get_icon("mem");

// Графические символы
const char* full_block = symbols.bar_full;
const char* border = symbols.border_h;
```

## Адаптивность

### Размеры терминала
- **Широкий терминал** (>120 колонок) - много колонок с детальной информацией
- **Средний терминал** (80-120 колонок) - оптимальная компоновка
- **Узкий терминал** (<80 колонок) - компактный режим с приоритетами

### Автоматическая компоновка

int panel_heights[3], panel_widths[2];

## Совместимость

### Поддержка терминалов
- **Современные терминалы** - полная поддержка Unicode и цветов
- **Старые терминалы** - автоматический fallback на ASCII символы
- **Ограниченная палитра** - адаптация к доступным цветам

### Производительность
- **Оптимизированные рендеринг** - минимальное воздействие на FPS
- **Кэширование цветов** - повторное использование цветовых пар
- **Условные эффекты** - отключение анимаций при необходимости

## Расширение системы

### Добавление новой темы
```c
// Определить цвета темы
static const short custom_theme_colors[COLOR_BTOP_MAX] = {
    [COLOR_BTOP_BG] = COLOR_BLACK,
    [COLOR_BTOP_TITLE] = COLOR_BLUE,
    // ... остальные цвета
};

// Использовать тему
memcpy(current_theme.color_pairs, custom_theme_colors, sizeof(custom_theme_colors));
strcpy(current_theme.name, "custom-theme");
```
