# 👨‍💻 ИНСТРУМЕНТЫ РАЗРАБОТЧИКА В SYSTEM MONITOR v2.0

## 📋 Обзор

System Monitor v2.0 включает мощный набор инструментов специально для разработчиков, которые помогают контролировать и управлять средой разработки прямо из терминала.

## 🔌 Мониторинг портов

### Функционал:
- Отображение всех занятых портов
- Информация о процессах, использующих порты
- Быстрое освобождение портов
- Определение типа сервиса

### Горячая клавиша: **[L]**

### Отображаемая информация:
```
Порт    Процесс         PID     Сервис           Доступ
────────────────────────────────────────────────────────
3000    node           12345    Dev Server       localhost
5432    postgres       23456    PostgreSQL       all
6379    redis-server   34567    Redis            localhost
8080    java           45678    Spring Boot      all
```

### Полезные команды:
- **[K]** - Освободить выбранный порт
- **[R]** - Перезапустить процесс на порту

### Типичные порты разработки:
- **3000-3002** - React, Next.js, Express
- **4200** - Angular
- **5000-5001** - Flask, Python servers
- **8000-8001** - Django
- **8080-8081** - Java, Spring Boot
- **5432** - PostgreSQL
- **3306** - MySQL
- **27017** - MongoDB
- **6379** - Redis
- **9200** - Elasticsearch

## 💡 Полезные советы

### Горячие клавиши для продуктивности:
- **[V]** - Быстрый доступ к меню разработчика
- **[L]** - Проверить занятые порты перед запуском сервера
- **[G]** - Быстрый обзор всех Git репозиториев
- **[E]** - Проверка окружения перед началом работы

### Автоматизация:
```bash
# Добавьте в ~/.zshrc или ~/.bashrc
alias sysmon-dev="sysmon && echo 'V'"  # Сразу в меню разработчика
alias ports="sysmon && echo 'L'"        # Сразу к портам
alias repos="sysmon && echo 'G'"        # Сразу к Git
```

### Интеграция с IDE:
- Можно запускать из терминала VS Code
- Интеграция с tmux для split-screen мониторинга
- Экспорт метрик в файл для CI/CD

## 🔄 Workflow примеры

### Начало рабочего дня:
1. **[E]** - Проверить окружение
2. **[G]** - Просмотреть статус репозиториев
3. **[L]** - Убедиться что порты свободны
4. **[V]→[2]** - Запустить нужные сервисы

### Отладка проблем:
1. **[L]** - Проверить конфликты портов
2. **[V]→[1]** - Найти зависшие процессы
3. **[V]→[3]** - Проверить логи на ошибки
4. **[V]→[2]** - Перезапустить проблемные сервисы

### Конец дня:
1. **[G]** - Закоммитить все изменения
2. **[V]→[2]** - Остановить базы данных
3. **[V]→[2]** - Docker system prune
4. **[S]** - Сохранить снимок системы

## 🆘 Решение проблем

### Порт занят, но процесс не найден:
```bash
sudo lsof -i:PORT
kill -9 PID
```

### Git репозиторий не отображается:
- Проверьте что папка в списке сканируемых директорий
- Убедитесь что есть папка .git

### База данных не запускается:
- Проверьте логи в /usr/local/var/log/
- Проверьте права доступа
- Попробуйте brew services restart
