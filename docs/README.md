# Системный монитор (SysMon) v2.0

Мощная кросс-платформенная утилита мониторинга системы с поддержкой macOS и Linux, написанная на чистом C с использованием ncurses для интерактивного интерфейса.

## 🚀 Возможности

### Основные функции мониторинга
- **Процессор**: Загрузка CPU по ядрам, частоты, температура
- **Память**: Использование RAM, детальный breakdown памяти
- **Процессы**: Список процессов с CPU/Memory usage, сортировка и фильтрация
- **Сеть**: Скорость RX/TX, информация о подключениях
- **Диски**: Использование дискового пространства, SMART атрибуты
- **Батарея**: Уровень заряда, статус, циклы (для ноутбуков)
- **Температуры**: Датчики CPU, GPU, жестких дисков
- **USB устройства**: Подключенные USB устройства

### Дополнительные функции
- **Погода**: Интеграция с wttr.in для отображения погоды
- **Графики**: Спарклайны истории загрузки CPU/Memory
- **Аномалии**: Обнаружение необычных паттернов использования
- **Экспорт метрик**: Поддержка Prometheus и Grafana
- **CSV логи**: Экспорт метрик в CSV для анализа
- **Дерево процессов**: Расширенный анализ процессов с визуализацией зависимостей
- **Экспорт дерева**: Поддержка TXT, JSON и DOT форматов для анализа процессов
- **Современный дизайн**: Интерфейс в стиле btop с градиентными барами и темами
- **Адаптивная компоновка**: Оптимизация для разных размеров терминала

### Инструменты разработчика
- **Мониторинг процессов разработки**: Node.js, Python, Docker и др.
- **Git репозитории**: Статус репозиториев, изменения, ветки
- **Порты**: Занятые порты и связанные процессы
- **Базы данных**: Статус PostgreSQL, Redis, MongoDB
- **Быстрые действия**: NPM команды, очистка кэша, перезапуск сервисов

## 📦 Установка

### Требования
- **macOS**: Xcode command line tools или gcc
- **Linux**: gcc, ncurses development headers
- **Опционально**: smartmontools, istats (для macOS)

### Сборка
```bash
make all        # Сборка основного приложения
make test       # Сборка и запуск тестов
make clean      # Очистка объектных файлов
```

### Зависимости
На macOS:
```bash
# Используя Homebrew
brew install ncurses
```

На Linux:
```bash
# Debian/Ubuntu
sudo apt-get install libncurses5-dev gcc

# CentOS/RHEL
sudo yum install ncurses-devel gcc
```

## 🎛️ Конфигурация

Программа использует переменные окружения для настройки:

### Основные настройки
- `SYSMON_SAFE=1` - Безопасный режим (отключает потенциально опасные модули)
- `SYSMON_NO_BAT=1` - Отключить мониторинг батареи
- `SYSMON_NO_GPU=1` - Отключить мониторинг GPU
- `SYSMON_NO_USB=1` - Отключить мониторинг USB

### Пороги аномалий
- `SYSMON_THR_CPU=90` - Порог CPU для предупреждений (%)
- `SYSMON_THR_MEM=95` - Порог памяти для предупреждений (%)
- `SYSMON_THR_TEMP=85` - Порог температуры для предупреждений (°C)

### Экспорт данных
- `SYSMON_CSV=/path/to/metrics.csv` - Путь для CSV экспорта
- `SYSMON_WEATHER_CITY=Москва` - Город для погоды

### Файл конфигурации
Создайте `config.ini` в корне проекта:
```
SYSMON_SAFE=0
SYSMON_THR_CPU=85
SYSMON_THR_MEM=90
SYSMON_WEATHER_CITY=Москва
```

## 🎯 Использование

### Запуск
```bash
# Основной режим
./sysmon

# С пользовательским конфигом
SYSMON_CONFIG=/path/to/config.ini ./sysmon

# Безопасный режим
SYSMON_SAFE=1 ./sysmon

# Отладочный режим
SYSMON_DEBUG=1 ./sysmon
```

### Горячие клавиши
- `P` - Список процессов
- `T` - Дерево процессов (расширенный анализ)
- `G` - Git репозитории
- `E` - Окружение разработчика
- `L` - Занятые порты
- `V` - Меню разработчика
- `A` - Быстрые действия
- `W` - Подробная погода
- `Q` - Выход

В списке процессов:
- `↑↓` - Навигация
- `K` - Завершить процесс
- `S` - Сортировка (PID/CPU/Memory)
- `/` - Фильтр по имени
- `PgUp/PgDn` - Страницы

## 🌳 Дерево процессов

### Возможности анализа процессов
- **Построение дерева**: Автоматическое построение иерархии процессов с родительскими связями
- **Визуализация зависимостей**: Графическое отображение связей между процессами
- **Анализ ресурсов**: Мониторинг CPU и памяти для всего поддерева процессов
- **Экспорт данных**: Поддержка экспорта в TXT, JSON и DOT форматы
- **Интерактивный режим**: Навигация и фильтрация процессов в реальном времени

### Использование дерева процессов
```bash
# Запуск основного монитора
./sysmon

# В интерфейсе нажмите 'T' для открытия дерева процессов
# Доступные действия:
# - A - ASCII визуализация дерева
# - E - Экспорт дерева в файл
# - Q - Возврат в основной интерфейс
```

### Демонстрация функционала
```bash
# Сборка и запуск демо
gcc src/process_tree_demo.c src/process_tree.c -o process_tree_demo
./process_tree_demo
```

## 🔧 Архитектура

### Модульная структура
```
src/
├── main.c           # Точка входа
├── ui.c             # Интерфейс пользователя (ncurses)
├── system_info.c    # CPU, память, uptime
├── processes.c      # Список процессов и статистика
├── process_tree.c   # Анализ дерева процессов
├── network.c        # Сетевая активность
├── disk.c           # Информация о дисках
├── config.c         # Конфигурация
├── logging.c        # Система логирования
├── mac_smc.c        # Температуры для macOS
├── linux_hwmon.c    # Температуры для Linux
└── ...              # Другие модули
```

### Платформо-зависимый код
- **macOS**: Использует Mach API, IOKit, System Management Controller
- **Linux**: Использует /proc, /sys/class/hwmon, thermal zones

## 🔍 Диагностика

### Диагностический режим
```bash
# Проверка доступности всех модулей
./sysmon
# Нажмите 'D' для диагностики
```

### Логирование ошибок
Ошибки логируются в stderr с временными метками:
```
[14:30:15 ERROR] Failed to read temperature sensor (errno: 2 - No such file or directory)
```

## 🚨 Безопасность

- **Безопасный режим**: Отключает потенциально опасные операции
- **Валидация ввода**: Проверка границ массивов и строк
- **Обработка ошибок**: Graceful degradation при недоступных модулях
- **Права доступа**: Минимальные требования для работы

## 🐛 Отладка

### Отладочный режим
```bash
SYSMON_DEBUG=1 ./sysmon
```

Отладочная информация включает:
- Шаги инициализации модулей
- Системные вызовы и их результаты
- Времена выполнения операций
- Состояние кэшей и буферов

## 🤝 Разработка

### Добавление нового модуля
1. Создайте заголовочный файл `src/new_module.h`
2. Реализуйте функции в `src/new_module.c`
3. Добавьте модуль в `Makefile`
4. Зарегистрируйте в `src/ui.c`

### Стиль кода
- Используйте 4 пробела для отступов
- Длина строки не более 120 символов
- Документируйте публичные функции
- Обрабатывайте все ошибки системных вызовов
